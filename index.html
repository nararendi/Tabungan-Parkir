Konfigurasi Database Cloud Supabase

Hubungkan web app ke database PostgreSQL Supabase untuk sinkronisasi data online

Mode Penyimpanan Lokal (Offline)

Cara Menghubungkan ke Supabase (Panduan Lengkap)

Ikuti 4 langkah mudah berikut untuk mengaktifkan database online

1
Buat Project Baru

Buka supabase.com, daftar/login, klik New Project, tentukan nama dan password database.

2
Jalankan Skrip SQL

Klik tombol "Salin Skrip SQL Supabase" di kanan atas. Buka menu SQL Editor di Supabase, buat New Query, tempel (Paste) lalu klik Run.

3
Ambil API Key

Di dashboard Supabase, klik Project Settings (ikon gear) > API. Salin Project URL dan anon / public key.

4
Simpan di Aplikasi

Tempelkan URL dan API Key ke formulir di atas, lalu klik Simpan & Hubungkan Database. Status akan otomatis berubah menjadi Terhubung (Cloud).
